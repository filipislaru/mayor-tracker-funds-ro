## Summary
The name normalisation helper `mayortracker.util.names.normalise_name`, Pydantic schemas for `uat` and `locality` records, CLI commands `mt ingest siruta`, `mt ingest lau-boundaries`, `mt ingest register-file`, and `mt normalise uat` have been implemented and fully tested. Eurostat GISCO LAU 2024 boundaries were successfully downloaded via `mt ingest lau-boundaries` (42.9 MB shapefile zip, SHA256 `8eb297d9...`, valid TLS cert from Eurostat). 

Ingestion of raw `siruta.csv` from data.gov.ro remains blocked because the upstream wildcard TLS certificate for `*.gov.ro` expired on 2026-10-09 GMT, and the alternative publisher INS (`insse.ro`) presents an anti-bot JavaScript challenge returning HTTP 503. To accommodate offline/manual acquisition without bypassing TLS verification, the general ingestion command `mt ingest register-file <path> --source-id <id> --source-url <url>` has been implemented and tested. It copies the user-supplied file into `data/raw/<source_id>/<date>/` and writes the manifest entry (`sha256`, `size`, `retrieval_method: manual`, `retrieved_by: user`, timestamp) while strictly enforcing raw file immutability. `mt normalise uat` seamlessly accepts files registered via this mechanism. In accordance with user instructions, `mt normalise uat` has not been run on real data; awaiting manual registration of `siruta.csv`.

## Blockers and open questions
1. **Upstream SSL Certificate Expiration on data.gov.ro**:
   - The wildcard TLS certificate on `*.gov.ro` expired on 2026-10-09 23:59:59 GMT (`notBefore=Sep 26 00:00:00 2025 GMT`, `notAfter=Oct 9 23:59:59 2026 GMT`).
   - Automated ingestion via `mt ingest siruta` fails standard TLS verification.
   - `insse.ro` requires a JavaScript and cookie challenge (HTTP 503 anti-bot shield).
   - **Resolution path**: User will download `siruta.csv` manually and run:
     ```bash
     uv run mt ingest register-file /path/to/siruta.csv --source-id siruta --source-url "https://data.gov.ro/dataset/26e9db4c-2afe-4d86-8a8f-caa879cae7ea/resource/1f023137-96d7-498c-a90f-75c13253615c/download/siruta.csv"
     uv run mt normalise uat
     ```
     This will copy the file into `data/raw/siruta/<date>/`, write the manifest entry, and produce the Parquet and GeoJSON tables.

## Risks and suggestions
- **Per-polygon simplification gaps**: Per-polygon geometric simplification can leave minute sliver gaps between adjacent communes on vector maps. As noted by the user, this is a styling/topological follow-up for the website map task (T013) using TopoJSON or MapLibre polygon styling.
- **Bucharest sectors missing from Eurostat LAU**: Eurostat GISCO provides the boundary for Bucharest as a single unit (`RO_179132`). Detailed sector boundaries will need to be obtained from ANCPI / geo-spatial.org in a future web mapping task.
