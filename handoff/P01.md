## Summary
The probe investigated whether textual requirements needed for a "tailored tenders" procurement integrity indicator can be obtained from SICAP (e-licitatie.ro) and TED (ted.europa.eu). Route A (SICAP tender documentation) is **not feasible** due to HTTP 403 anti-bot enforcement on API endpoints without browser Referer headers and HTTP 500 errors on attached document endpoints; Terms of Use on automated access are unverified, to be checked by the user. Route B (TED notices) is **feasible**: the official open Search API v3 (`api.ted.europa.eu/v3/notices/search`) requires no API key or registration, and delivers complete XML notices containing detailed selection-criteria and technical text in Romanian (averaging ~15,000 characters in standard forms and ~64,000 characters in eForms). Route C (TED $\leftrightarrow$ SICAP Linkage) is **feasible**: 100% of tested TED notices (20/20) embed the direct SICAP notice URL and identifier, making cross-referencing deterministic.

## Blockers and open questions
1. **SICAP bulk download blocker:** Programmatic access to `e-licitatie.ro` is blocked by technical protections (HTTP 403 without browser Referer, HTTP 500 on document download endpoints); Terms of Use on automated access are unverified, to be checked by the user. No authorized public API exists.
2. **Decision for tailored tenders measure:** Above-threshold tenders should rely on TED notices for qualification/technical criteria text. Below-threshold tenders in SICAP will either require an official institutional data agreement with ADR/ANAP or remain unmeasured for textual tailoring.

## Risks and suggestions
- **Coverage limitation:** TED notices cover public procurement contracts above EU publication thresholds (~5.3M EUR for works, ~215k EUR for supplies/services for sub-central authorities). Smaller rural commune contracts below these thresholds are published only on SICAP and cannot be scraped legally without ADR agreement.
- **NLP pipeline design:** A future extraction task for tailored tenders can directly query the TED Search API v3 without an API key, download XML, and extract Romanian text from `LEFTI` (standard forms) or `SelectionCriteria` / `SubordinateAwardingCriterion` (eForms), cross-referencing contracts via the embedded SICAP `noticeId`.
