## Summary
The probe investigated whether textual requirements needed for a "tailored tenders" procurement integrity indicator can be obtained from SICAP (e-licitatie.ro) and TED (ted.europa.eu). Route A (SICAP tender documentation) is **not feasible**: Terms of Use explicitly state: *“Accesul la platformă și la interfețele sale publice este destinat utilizării individuale! Este interzisă accesarea platformei prin mijloace automate (roboți, scripturi, programe de tip crawler sau scraper) în scopul extragerii sistematice de date, cu excepția integrărilor autorizate de operatorul platformei.”* (verified by the user in a browser on 2026-10-10, `https://e-licitatie.ro/pub/staticpages/TermsAndConditions`). No automated access to e-licitatie.ro; a possible later route is an authorised integration via the platform operator (ADR). In addition, programmatic HTTP requests without browser Referer headers are blocked by technical controls (HTTP 403 `Access Denied: Referrer cannot be null`) and attached document endpoints return HTTP 500 errors. Route B (TED notices) is **feasible**: the official open Search API v3 (`api.ted.europa.eu/v3/notices/search`) requires no API key or registration, and delivers complete XML notices containing detailed selection-criteria and technical text in Romanian (averaging ~15,000 characters in standard forms and ~64,000 characters in eForms). Route C (TED $\leftrightarrow$ SICAP Linkage) is **feasible**: 100% of tested TED notices (20/20) embed the direct SICAP notice URL and identifier, making cross-referencing deterministic.

## Blockers and open questions
1. **SICAP bulk download blocker:** Automated scraping of full documentation from `e-licitatie.ro` is prohibited by ADR's Terms of Use (verified by the user on 2026-10-10) and blocked by technical protections (HTTP 403 without browser Referer, HTTP 500 on document download endpoints). No automated access to e-licitatie.ro; a possible later route is an authorised integration via the platform operator (ADR).
2. **Decision for tailored tenders measure:** Above-threshold tenders should rely on TED notices for qualification/technical criteria text. Below-threshold tenders in SICAP will either require an official institutional data agreement with ADR/ANAP or remain unmeasured for textual tailoring.

## Risks and suggestions
- **Coverage limitation:** TED notices cover public procurement contracts above EU publication thresholds (~5.3M EUR for works, ~215k EUR for supplies/services for sub-central authorities). Smaller rural commune contracts below these thresholds are published only on SICAP and cannot be scraped legally without ADR agreement.
- **NLP pipeline design:** A future extraction task for tailored tenders can directly query the TED Search API v3 without an API key, download XML, and extract Romanian text from `LEFTI` (standard forms) or `SelectionCriteria` / `SubordinateAwardingCriterion` (eForms), cross-referencing contracts via the embedded SICAP `noticeId`.
